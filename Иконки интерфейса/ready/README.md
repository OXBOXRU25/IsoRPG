# Иконки кнопок нижнего ряда — готовые к встройке

Семь штук, нарезаны и выровнены 03.09.2026.

## Что это

Кнопки ряда в правом нижнем углу экрана. Загружаются кодом из `Resources`,
размер кнопки в `HudBar.cs` — **48 пикселей**.

| файл | кнопка | заменяет |
|---|---|---|
| `UI_Bag.png` | сумка | старый `UI_Bag.png` |
| `UI_Character.png` | персонаж | старый `UI_Character.png` |
| `UI_Journal.png` | квесты, свиток | старый `UI_Journal.png` |
| `UI_Settings.png` | настройки, шестерня | старый `UI_Settings.png` |
| `UI_Talents.png` | таланты, звезда | старый `UI_Talents.png` |
| `UI_Map.png` | карта | новая |
| `UI_Guild.png` | гильдия, знамя | новая |

Старые лежат в `Assets/_Game/Art/UI/Icons/Buttons/` — плоская мультяшная графика
с чёрным контуром и **запечённым тёмным фоном** (альфа 255 по углам). Их надо
заменить все пять: рядом с новыми они из другой игры.

## Формат

- **512×512, PNG с альфой.** Фон полностью прозрачный, подложку даёт ячейка.
- Предмет вписан в квадрат с полем 12% по каждой стороне, пропорции сохранены:
  огибающая у всех одна, ширина и высота отличаются по форме предмета.
- Пурпурный фон генератора снят по замеру (он был не `#FF00FF`, а около
  `(253,20,249)` и гулял от кадра к кадру), кромка очищена от пурпурной примеси.

## Настройки импорта в Unity

- **Texture Type:** Sprite (2D and UI)
- **Alpha Is Transparency:** включить
- **Max Size: 256.** Показываются они на 48 пикселях; 512 в сборке — лишний вес
  без единого видимого пикселя выигрыша.
- **Compression:** обычная, но если по краю полезет грязь — поставить без сжатия,
  иконок всего семь.

## Стиль, если понадобится дорисовать восьмую

Тёплая рисованная манера набора `GUI_Fantasy_Kit` (`Assets/Assets/GUI_Fantasy_Kit`):
округлые формы, мягкая растушёвка, один насыщенный акцент на иконку, тонкий
неровный тёмный кант по краю (около 1.5% ширины, сильнее снизу справа, почти
исчезает сверху слева, где падает свет). Полные промты — в чате от 03.09.2026.

**Правило отбора сюжета:** предмет должен иметь несколько материалов и выпуклость.
Плоские вещи в этой манере проваливаются — на карте и на щите мы обожглись оба
раза, пока карту не завернули по краям, а щит не заменили на знамя.
